Overview

This is the opening session of the Agentic AI & Vibe Coding program delivered by UNDP in partnership with UN Volunteers. The session introduces fundamental concepts of Vibe Coding and sets the stage for the comprehensive 10-session program covering AI-driven development, security practices, and agentic systems.

  1. Understanding Vibe Coding - Shift from traditional line-by-line coding to AI-powered development
  2. Recognizing the Evolution of AI - Three phases of AI coding development
  3. Markdown as AI Native Language - How to communicate effectively with AI models
  4. Token Cost Optimization - Practical tips for cost-effective AI usage
  5. Overview of the Complete Program - Understanding the 10-session roadmap

Main Topics Covered

1. Why Vibe Coding for Developing Countries

  • Historical Context: Professional software development required 4-5 years of practice and was expensive
  • Current Reality: AI enables rapid prototyping; junior developers can work like senior architects
  • Critical Insight: Speed is no longer an advantage—Quality and Security become the differentiator
  • The Paradigm Shift: Your advantage lies in ensuring fast code is also safe, strong, and professional

2. What is Vibe Coding?

Traditional approach: - Type every bracket and semicolon - Search documentation manually - Decide line-by-line what to build and how

New approach: - You decide WHAT to build - AI decides HOW to build it - Your speed depends on how clearly you explain your idea to the AI - Famous researcher quote: “The hottest new programming language is English”

3. Three Phases of AI Coding Evolution

Phase Period Capability Limitation
Phase 1 2021-2022 AI guesses the next line Limited context awareness
Phase 2 2022-2024 Chat assistance (copy-paste) Cannot see full project
Phase 3 Today Agents - Read entire project, create files, run commands, test, fix mistakes Most powerful, still needs oversight

  • AI Models/Engines: Claude (Opus, Sonnet), GPT (various), Gemini, DeepSeek
  • Key Concept: Editor = Car Body; AI Model = Engine
  • Extension Options: Claude Code, VS Code extensions for seamless integration

5. Communicating with AI: Markdown Format

AI models are trained primarily on content from GitHub, Stack Overflow, and technical documentation—all written in Markdown format. This makes Markdown the “native language” of AI.

Best Practices: - Hash signs (#) = Mark important sections - Code blocks (```) = Clearly show code boundaries - Bullet points = Show order and priority - Together = Reduces hallucination significantly

Example approach:

# Login System Requirements
## Functional Requirements
- User registration with email validation
- Secure password storage (bcrypt)
- Session management with JWT tokens

## Constraints
- NO passwords in code
- NO hardcoded credentials
- MUST follow OWASP standards

6. Token Cost & Optimization

Every word sent to AI incurs costs measured in “tokens.”

Three Money-Saving Tips: 1. Use System Prompts - Put fixed rules at the top (can be 10x cheaper when reused) 2. Send Only What’s Needed - Don’t send entire projects to fix one function 3. Model Selection - Use smaller models for easy tasks; reserve big models for complex work (design, security)

Enterprise Impact: Significant cost savings for organizations running many AI operations

8. Core Program Philosophy

“Technology is a tool, but security is the foundation upon which trust is built.”

Action Items for Participants: - Start thinking like a manager or auditor, not a traditional programmer - Your job shifts to deciding what good code looks like and verifying it - Embrace the responsibility of quality assurance over code creation

Key Takeaway

Vibe Coding is not about blindly trusting AI to write code—it’s about leveraging AI efficiency while maintaining human oversight and responsibility for security, quality, and professional standards. The goal is to democratize software development for talented people in developing countries who previously lacked access to expensive developers and extended timelines.
